# Driver patch artifacts

`p2p48g-595.99.02-port.patch` is the tracked-source diff used to build the
locally evaluated NVIDIA 595.99.02 open kernel modules. It is provided for
review and reproducibility, not as a promise of compatibility with another
driver release. Apply only to the matching upstream tag and retain a stock
rescue boot entry.

The patch does not contain NVIDIA firmware, model weights, credentials, or
compiled kernel modules.
